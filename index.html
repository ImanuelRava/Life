Formatting tips

Word-like formatting: select text, then use the Home ribbon tab — bold, italic, colors, highlight, alignment, lists, quotes and code blocks are wrapped automatically.

Sections & TOC: \section{...} is auto-numbered (toggle in Page Layout). Insert \tableofcontents to build a clickable TOC with page numbers.

Math: inline $x^2$, display \[ ... \], numbered \begin{equation}...\end{equation}, and \begin{align}...\end{align} all render live via KaTeX.

Symbols anywhere: buttons on the Operators, Relations, Symbols, Fractions and Calculus tabs work even in plain text — the editor wraps them in $…$ automatically, and math commands typed by hand (like \alpha or \leq) fall back to their Unicode symbol.

Images: use the Image button (Insert group) — files are embedded, so they survive reloads and PDF export. Referenced as \includegraphics[width=0.7\textwidth]{name}.

Footnotes: \footnote{...} places a superscript marker and renders the note at the bottom of that page.

Page setup: paper size, margins, font size and line spacing live in the Page Layout ribbon tab (gear icon above the preview).
